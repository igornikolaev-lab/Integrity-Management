# Як подати IntegrityOS на хакатон

## Публічний GitHub-репозиторій

1. Увійдіть на <https://github.com/>. Натисніть **New repository**.
2. Назва: `integrityos-hackathon`. Visibility: **Public**. Створіть репозиторій без зайвих файлів (або завантажте файли після створення).
3. **Add file → Upload files**: завантажте **вміст розпакованої папки** `integrityos/`, зберігаючи відносну структуру директорій. Не завантажуйте `data/*.sqlite`, `__pycache__`, `.env` або персональні відомості.
4. Натисніть **Commit changes**. Перевірте, що головний `README.md` відкривається автоматично.
5. Скопіюйте URL виду `https://github.com/ВАШ_ЛОГІН/integrityos-hackathon` у форму організаторів. **Не копіюйте** адресу окремого файлу `README.md` замість адреси репозиторію.

Альтернатива через Git:

```bash
cd integrityos
git init
git add .
git commit -m "Initial IntegrityOS hackathon MVP"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/integrityos-hackathon.git
git push -u origin main
```

## Демонстраційне відео (до 3 хвилин)

У пакеті є `demo-integrityos.mp4` — беззвуковий відеоогляд зі скриншотів реального інтерфейсу, і `docs/PITCH_SCRIPT.md`. Для максимальної відповідності формату відеодемонстрації бажано перезаписати ролик із реальними кліками та короткою озвучкою. Завантажте відео у GitHub Releases або додайте до репозиторію, якщо його розмір дозволяє. Додавайте посилання на відео до README або у форму організаторів. За необхідності перезапишіть відео з голосовим коментарем команди — ролик-приклад демонструє екрани прототипу.
