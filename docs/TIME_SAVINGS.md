# Модельна економія часу на підготовку аналітичних матеріалів

Припущення для демонстрації, **не реальні вимірювання персоналу**. Кількість безпечно агрегованих учасників у початковому циклі `N = 41`.

| Операція | Ручна робота | IntegrityOS |
|---|---:|---:|
| Обробка одного опитувальника | 4 хв × 41 = 164 хв | 0,4 хв × 41 ≈ 16 хв |
| Узагальнення, графіки, підготовка звіту / перевірка | 180 хв | 25 хв |
| **Разом** | **344 хв (5 год 44 хв)** | **≈ 41 хв** |

**Потенційна економія ≈ 303 хв (5 год 3 хв), тобто 88% часу** у наведеному умовному сценарії. Результат буде іншим для іншої кількості відповідей, якості даних і фактичної трудомісткості роботи.

В інтерфейсі «Звіти та експорт» усі чотири параметри можна змінювати; новий час перераховується без перезапуску. Формули:

```
T_manual = N × t_manual_per_form + t_manual_report
T_auto   = N × t_auto_per_form   + t_auto_verification
Savings  = max(0, T_manual − T_auto)
Savings% = Savings / T_manual × 100%
```

Для доказової оцінки ефекту після пілотного впровадження необхідно виміряти час на контрольних циклах, урахувати навчання користувачів, валідацію якості та підтримку системи. Оцінка не використовується як твердження про досягнуту економію у ЗСУ чи будь-якій реальній установі.
